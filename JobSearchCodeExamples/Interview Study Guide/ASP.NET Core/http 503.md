# HTTP 503 Service Unavailable Error

#### What is it?
Service Unavailable.

#### Why does it exist?
To tell clients the server is temporarily unable to process requests.

#### When would I use it?
Maintenance, overload, unavailable dependencies.

#### Interview answer
"503 indicates the server is temporarily unavailable. Unlike a 500, the server is functioning correctly but cannot currently process the request."
